Пример создания игры на микропайтоне для простого чернобелого ЖКИ экранчика (176х128 пикселей) контроллера EV3. 
Движение Пакмана управляется кнопками EV3 (вверх-вниз, вправо-влево). Пакман начинает движение по нажатию на кнопку, и продолжает движение после отпускания кнопки до препятствия в виде стенки лабиринта, где он останавливается, или до нажатия на следующую кнопку, задающую новое направление. Но, если изменить направление движения для поворота Пакман сразу не может (так как, например мешает стенка лабиринта), то он запоминает заданное новое направление и продолжает движение в предыдущем направлении до проёма в стенке лабиринта в новом заданном направлении, и только тогда изменяет направление движения. Пакман движется смещаясь на один пиксель, но повернуть в лабиринте может только находясь в центре клетки лабиринта размером 16х16 пикселей. При задании движения назад, то есть в противоположном текущему направлению движения, Пакман не ждет центра клетки лабиринта, а сразу меняет направление на обратное. В первом варианте игры лабиринт один. Пакман просто должен пройти по всем доступным клеткам лабиринта, съедая по одной точке в центре каждой клетки и получая за это один игровой бал. В последствии предполагается ввести новые уровни и новые схемы лабиринтов, улучшить подсчет баллов и ввести охотников на Пакмана, а также магических звездочек, при съедании которых Пакманом охотники на какое то время становятся целями, которые Пакман может съесть.
